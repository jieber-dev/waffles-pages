Privacy Policy

for the Waffles Telegram assistant

Last updated: 16 September 2026

Waffles is a single-user, personal-use Telegram bot. It is not distributed publicly and has exactly one operator/user. This policy explains what data it accesses and how that data is used.

What Waffles accesses

Telegram messages: messages sent to the bot are read in order to log tasks/events or answer questions. Messages are not shared with any third party except as described below (message classification).

Google Calendar (read-only): Waffles reads calendar events to answer questions like "what's on today" and to build a daily briefing. It never creates, edits, or deletes anything on the calendar.

Microsoft To Do (read/write): Waffles reads pending tasks to include in the daily briefing, and creates new tasks when asked to log one.

Message classification (OpenRouter): the text of a message may be sent to a third-party language model API (via OpenRouter) to determine whether it describes a task or an event and to extract relevant details (title, date, time, location). No data beyond the message text itself is sent for this purpose.

Data storage

A log of captured tasks/events and lightweight app state (such as workout history) is stored in plain files on the server running the bot. This data is not sold, shared, or used for advertising, and is only accessible to the bot's single operator.
